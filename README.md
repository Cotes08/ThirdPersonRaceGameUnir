# RaceGame

A racing prototype developed in **Unreal Engine 5**, designed to experiment with AI and racing mechanics.

## Key Features

- Advanced AI system: AI drives optimally around the track and tries to overtake slower cars.  
- Collision-aware AI for a more aggressive racing experience.  
- GameState tracks player position and lap count.  
- Lap system and position tracking displayed in real-time.  
- Victory and defeat system: finish first to win, otherwise lose.  
- Race manager: cars stay static until countdown finishes.  
- Vehicle adapted for both player and AI control.  
- Dynamic camera system based on speed.  
- Realistic track environment: night and sunset settings, mountains, lighting, asphalt texture, and track barriers.  

## Controls

- **Accelerate:** W / Right Trigger  
- **Brake:** S / Left Trigger  
- **Steering:** A/D or Left Joystick  
- **Handbrake:** Space / X (PlayStation) / A (Xbox)  
- **Camera:** Mouse / Right Joystick  
- **Reset Vehicle:** R / Triangle (PlayStation) / Y (Xbox)  
- **Return to Main Menu:** Escape / Start Button
